процесс 4 шага

цикл редакции

От первой строки до ответа API — путь записи не выходит за пределы Verso.

01

запись

Черновик в коллекции: блоки собраны в конструкторе, автор назначен.

02

ревизия

Правки и снапшоты: карточка едет по канбану редполитики.

03

публикация

По расписанию или сразу: запись получает статус published.

04

headless-выдача

Front-end забирает запись через API — с read-ключом vrs_live_….
