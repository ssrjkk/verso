Контент с редактурой, а не CRUD.

Рабочий цикл редакции: коллекции, ревизии, канбан редполитики и headless-выдача. Схема полей настраивается под отрасль — блог, услуги, товары, недвижимость. Блоки собираются мышью или с клавиатурой, каждое сохранение остаётся снапшотом, каждый статус — шаг редполитики.

SSRF-safe вебхуки

Исходящие вебхуки с автоматическими ретраями; адресаты проверяются при сохранении и перед каждой отправкой — локальные хосты и приватные диапазоны недоступны.

запись

Правки и снапшоты: карточка едет по канбану редполитики.

03

публикация

По расписанию или сразу: запись получает статус published.

04

headless-выдача

Front-end забирает запись через API — read-ключ vrs_live_… отдаёт только опубликованное.
